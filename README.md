## Fonctionnalités

- choix pierre, feuille ou ciseaux ;
- résultat immédiat de la manche ;
- classement et statistiques ;
- persistance avec localStorage ;
- interface responsive.

## Consulter localement

Ouvrir index.html ou lancer un serveur statique :

    python -m http.server 8000

Projet de formation consacré aux événements JavaScript et au stockage local.
